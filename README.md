# 霓虹突破 · NEON BREACH

一款支持电脑和手机的俯视角射击游戏。选择武器与技能，在敌潮中移动、射击、闪避，收集点数并挑选强化，挑战关卡或无尽模式。

## 开始游戏

[下载并打开独立 HTML 版](霓虹突破.html)：保存文件后用 Safari、Chrome 或 Edge 打开即可游玩，无需安装。

手机建议横屏游玩。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左侧摇杆 |
| 开火 | 按住空格 / 鼠标左键 | 长按开火按钮 |
| 换弹 | R（打空后自动换弹） | 点击弹量按钮 |
| 大招 | Q | 点击技能按钮 |
| 闪避 | Shift | 点击闪避按钮 |
| 强化 | U | 点击点数按钮 |
| 使用道具 | F / G | 点击道具槽 |
| 暂停 | Esc / 暂停按钮 | 暂停按钮 |

在背包中选择武器和技能。闯关模式迎战敌潮与 Boss；无尽模式每八波进入补给站，可换装备并购买道具。教学关介绍基础操作。设置中可以调整声音、震屏和自动开火。

无尽进度、设置和最高分保存在当前浏览器。暂停或补给站可保存并退出，之后从主页继续挑战。清除浏览器数据会一并清除本机存档。
