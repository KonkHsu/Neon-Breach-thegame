# 霓虹突破 · 独立 HTML 网页版

双击本目录中的「霓虹突破.html」即可游玩，无需安装、联网或 Toy 账号。美术、音频和代码全部内嵌，移动这个 HTML 文件即可分享游戏。建议使用最新版 Chrome、Edge 或 Safari。

本副本来自当前 Toy 项目，保留开场、主页、背包、图鉴、设置、战斗界面、闯关、无尽、教学、武器、技能、强化、敌人和原有数值。按要求删除排行榜入口及功能；取消 Toy SDK、账号授权、云存储与平台横屏接口，采用浏览器本机存档。原项目未修改。

## 操作

- WASD / 方向键移动；鼠标左键 / 空格开火；R 换弹。
- Q 使用所选大招；Shift 闪避；U 购买强化；F / G 使用道具。
- Esc 暂停，设置中可开启自动开火。
- 手机横屏使用原有摇杆和触摸按钮；浏览器不支持自动旋转时手动横屏。
- 无尽模式暂停或补给站可「保存并退出」，回到主页使用「继续游戏」。仍从原有检查点恢复。

## 存档

存档、设置和最高分保存在当前浏览器，与原 Toy 项目的存储键隔离。清理浏览器数据会删除存档。直接打开 HTML 时，不同浏览器对文件存储规则不同，移动或重命名文件可能导致原存档不可见；长期游玩建议固定文件路径，或将 dist 部署到固定网址。

## 网站部署与开发

「dist」目录可直接部署到任意静态网站，支持子路径。双击版无需服务器；dist/index.html 应通过网站服务访问。

需要 Node.js 20.19+ 或 22.12+：

```sh
npm ci
npm run dev
npm test
npm run build
```

构建同时更新 dist 和「霓虹突破.html」。src 保留可编辑源码。原素材署名与许可保留在 SOURCES.md 和 public/licenses，游戏内「鸣谢」仍可打开。
